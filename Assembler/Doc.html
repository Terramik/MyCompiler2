Базовое

Команды(за некоторыми исключениями) пишутся так же как указано в документации процессора. Регистр не важен(за исключениям в случае меток прыжков и псевдонимов) 

OPP xor r0 R1
StOp

Команды в целом принимают 2 вида аргументов - номера регистров(начинаются с 0) и числовые значения.

Номера регистров - это либо конструкция вида R<номер регистра> либо его псевдоним: CP(r15), FL(r14), SF(r13)

Числовые значение - это числа в десятичной(123, 10), двоичной(0b101, 0b0011) или шестнадцатеричной системе(0xfa91), Также к ним можно добавить минус, тогда они будут записаны в виде дополнительного кода(размер зависит от количества байт для аргумента в команде)

r1 R2 FL
10 0xff -1 0b11

Команды на разных строчках будут разделены автоматически, а для разделения на 1 строчка нужно использовать ";". Комментарии начинаются с "#" и после этого символа всё до начала новой строки игнорируется. 

PASS; PASS # 2x pass
STOP
Дополнительное

CONST тут изменён, сам CONST - может транслироваться как команда CONST или как CONST_HALF (в зависимости от длинны константы, то есть 0xffff - CONST_HALF, 0xffffffff - CONST, отрицательные числа всегда CONST). Для определённых CONST и CONST_HALF используйте команды CONST_WORD и CONST_HALF соответственно. В них можно писать как положительные, так и отрицательные числа. Если они будут отрицательными: будут записаны в дополнительном коде согласно данной длине. Если они положительные, то будут просто записаны, без учёта дополнительного кода. Таким образом для CONST_HALF лимиты это [-2^15, 2^16). И также для CONST_WORD.

JUMP тоже изменён, теперь он прыгает не на определённое число байт(это считает сам ассемблер), а на специальную метку. Она создаётся командой LABEL <имя метки>, а сама команда теперь - JUMP condition <имя метки>. Прыжком к метке переводит указатель на следующею команду после неё. 

PASS
label loop
PASS
jump no loop # перепрыгнет ко второму pass

Псевдонимы, создаются ALIAS <имя> <значение>, значением могут быть числа, и регистры. После имена псевдонимов можно будет использовать в командах, и вместо строки будет использовать их значение. 

alias dest r0
alias val 1
const dest val # запишет в r0 значение 1
