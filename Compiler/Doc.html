Описания языка

Базовые штуки

Язык статически типизирован и компилируем в машинный код для моего процессора.

В целом язык состоит из 2-х частей - конструкций управления потоком и выражений операторов. Конструкции управления потоком, далее - инструкции, управляют тем, какие выражения и иные инструкции будут исполнены. Выражения операторов, далее - выражения, производят сами вычисления, и состоят в инструкциях.

Также в языке есть 2 типа значений, wvalue и rvalue. Это место, куда можно писать, и место, откуда можно читать соответственно. Почти всегда - wvalue это rvalue, но в обратную сторону это не так.

Чем является тот или иной участок памяти и как с ним работать определяет тип - см. его описания.

Нотация
  • exp - некое выражение>
  • wvalue - выражение, что является wvalue>
  • rvalue - выражение, что является rvalue>
  • ... - ряд неких инструкций>
  • {...} - блок инструкций>
Тип

Отображает, какой смысл имеют данные, и что с ними можно делать.

Есть несколько, все они - числовые, и один немного необычный числовой.

Без знаковые - uint8, uint16, uint32, uint64.

Знаковые - int8, int16, int32, int64.

И особый - bool, на нём работают условия и логические операторы

Приведение типов

Производиться неявно и с помощью специального оператора

В данном случае, все типы проводимы друг к другу.

В операторах типы меньше 1 слова будут расширены до него.

Block { ... }

Содержит ряд инструкций в "{}".

В случае обычной встречи будет выполнять внутренние инструкции друг за другом, Но он также может быть частью других инструкций, и тогда его работа будет зависеть от них

Conditional

Инструкция выбора, состоит из 3 частей. Первая часть - обязательное начало - if. Вторая часть - произвольное количество после первой - elif. Третья часть - завещающая, необязательная - else

if <условие> {...}, если условие(rvalue, bool) это true, исполняет данные блок кода и переходит к следующей инструкции, в противном случае исполняет следующею часть условия(если есть) или переходит к следующей инструкции.

elif <условие> {...}, такое же, как и if.

else {...}, если есть, и все проверки elif и if провалились - выполняет данный блок кода и после переходит к следующей инструкции.

Cycle While while <условие> { ... }

Если условие(rvalue, bool) это true, выполняет блок кода и возвращает к этой проверки, исполняя блок кода раз за разом, пока rvalue не станет false, и после он перейдёт к следующей инструкции. Также, может управляться особыми инструкциями.

Cycle Controls break; continue;

Работают с ближайшем по вложенности циклом. Команда break - прерывает исполнение блока кода и переходит к следующей инструкции(так, будто цикл получил false). Команда continue - прерывает исполнение блока кода и вызывает перепроверку цикла(он может продолжиться).

Function Definition def <имя> (<пареметры>) -> (<результаты>) { ... }

Объявление функции, создаёт функцию, которую потом можно вызвать специальным оператором. <пареметры> - через запятую, список всех параметров вида <имя> <тип>, как объявление переменной, но без "var". Они являются такими же переменными, как и обычные, но в них при запуске функции будут лежать переданные в её вызове аргументы. <результаты> - список типов результатов функции.

Function Return return <возвращаемые значения>;

Прерывает исполнение функции и возвращает <возвращаемые значения>(что должны соответствовать оным из сигнатуры функции).

Вызовы функции и прочее

Все переменные(переменные, временные значения в выражениях и аргументы) расположены на стеке, и насчитываются от SF + их смещение, и считаются исходя из их размера. Адреса, куда писать результаты тоже передаются в функцию в такие же места.

Процедура вызова функции: Взять заранее выделенное место для нового SF. Записать в зависимости от функции данные её аргументов и куда писать результаты. Записать туда текущий SF и CP, после передать CP функции. Завершение: Записать значения возвращаемые значения по нужным адресам, восстановить прошлый SF и CP.
